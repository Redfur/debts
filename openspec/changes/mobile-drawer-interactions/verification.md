# Проверка реализации

Дата: 9 ноября 2026. Среда: macOS, Google Chrome headless, CDP, изолированные временные профили. Данные рабочего профиля браузера не использовались.

## Команды

Для браузерного стенда запустить `npm run dev -- --host 127.0.0.1 --port 4189`, затем:

```sh
node scripts/check-drawers.mjs
```

Стенд `scripts/drawer-fixture.html` загружает настоящие компоненты всех семи окон и отдельную форму с Radix Select/Popover. Он не входит в production-сборку. Дополнительных тестовых зависимостей нет. `CHROME_PATH` позволяет указать другой путь к Chrome. Скрипт выводит путь временного профиля со снимком экрана и логом Chrome.

Для production-проверки запустить сборку и preview:

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4190
DRAWER_TEST_URL=http://127.0.0.1:4190/ node scripts/check-drawers.mjs "$(pwd)/scripts/drawer-offline-scenarios.mjs"
```

Повторная адресная проверка ручек:

```sh
DRAWER_TEST_SECTION=handles node scripts/check-drawers.mjs
```

## Фактические результаты

- Полный браузерный прогон прошёл: границы 1023/1024 px, один активный backend, доступное имя, сохранение режима и ввода при смене ширины, последующее открытие в новом режиме, композиция asChild.
- Все семь потребителей проверены на 390/1440 px в светлой/тёмной темах: открытие, отмена, повторное открытие. Мобильный свайп не сохраняет форму и не запускает подтверждаемое действие.
- Проверены расстояние и скорость свайпа, короткое медленное движение, touchCancel/pointercancel, свободный заголовок, сохранение выбранной валюты, исключение поля поиска, SVG внутри кнопки и выделенного текста. Отдельный заключительный прогон подтвердил размер ручки не меньше 44×44 px и закрытие всех семи окон.
- Жест на свободном заголовке прокрученного списка остаётся прокруткой до его начала; новый жест сверху закрывает окно. Ручка закрывает окно при ненулевом scrollTop.
- Вложенный выбор валюты сохраняет заметку родительского долга и возвращает фокус. Проверены Radix Select/Popover, независимое подтверждение NiceModal поверх окна, Tab внутри верхнего слоя и сохранение scroll-lock после закрытия дочернего окна.
- Управляемые незавершённые Promise проверили блокировку свайпа, Escape, фона, отмены и повторного выполнения у подтверждения, импорта, погашения и изменения долга. Ошибка снимает блокировку; успешное выполнение закрывает окно. Два намеренных отклонения onConfirm видны как «Тестовая ошибка» в логе браузера: проверка подтверждает, что ошибки не проглатываются.
- Проверены завершение hide перед callback «Открыть счёт» на обоих backend, повторные открытия, reduced-motion и возврат фокуса после удаления исходной кнопки.
- Уменьшение viewport до 390×500 сохраняет доступность поиска и положительную высоту списка, восстановление размера работает. Старый --keyboard-inset в Drawer отсутствует.
- Production PWA прошла отдельный прогон с отключённой сетью после установки service worker: первое открытие ленивых экранов, 155 валют, поиск THB и сохранение предпочтения после обычной офлайн-перезагрузки, история изменений, отмена сброса, неизменность сохранённого черновика после свайпа, вложенное изменение долга и погашение. При свежем кэше курса новых внешних runtime-запросов не было. Hard reload Chrome с обходом service worker не используется как проверка обычного запуска PWA.
- Внешний вид выбора валюты дополнительно просмотрен по снимкам production-сборки на 390/1440 px в обеих темах.
- `npm run check`, `npm run knip`, `npm run spec:validate`, `npm run build`, `git diff --check` прошли. Строгая проверка OpenSpec: 13 из 13. Стенд также отдельно проверен TypeScript с добавлением его файла к include конфигурации приложения.

## Невыполненная проверка

Задача 5.2 остаётся открытой: реальные iOS Safari и Android Chrome, системная клавиатура и нативная touch-прокрутка. Пользователь проверит это на своём устройстве. Эмуляция Chrome не считается заменой. До получения результата изменение не архивировано.

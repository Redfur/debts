# Spec Delta

## MODIFIED Requirements

### Requirement: Сведения в диалоге установки
Система SHALL сообщать браузеру название приложения, описание учёта долгов и офлайн-работы, иконку без обязательной обрезки и скриншоты основных экранов. Описание SHALL соответствовать поставке: только местные данные у статической, необязательная синхронизация у серверной. Обновление на прежнем origin сохраняет идентичность PWA; установка другого домена не считается автоматическим обновлением старой.

#### Scenario: Подробный диалог на Android
- **WHEN** пользователь нажимает «Установить» в Chrome на Android
- **THEN** системный диалог показывает название, достоверное описание и скриншоты приложения

#### Scenario: Обновление уже установленного приложения
- **WHEN** приложение было установлено до этого изменения и получает новую версию на прежнем origin
- **THEN** на экране «Домой» остаётся одна иконка с прежними данными, аккаунт автоматически не подключается

#### Scenario: Смена языка перед установкой
- **WHEN** пользователь выбирает English до установки приложения
- **THEN** приложение передаёт браузеру английские название Debts, описание и ярлыки, сохраняя прежнюю идентичность и адрес запуска

#### Scenario: Уже установленный ярлык
- **WHEN** пользователь меняет язык уже установленного приложения
- **THEN** внутреннее название меняется сразу, приложением предоставлены актуальные локализованные сведения установки
- **AND** фактическое переименование системной иконки и обновление ярлыков происходят по возможностям и правилам браузера/ОС; приложение не обещает мгновенного переименования и не требует удаления данных

#### Scenario: Серверная установка
- **WHEN** пользователь устанавливает серверную поставку
- **THEN** описание не обещает, что все данные всегда остаются только на устройстве

## ADDED Requirements

### Requirement: Переезд установленной PWA между доменами
Система SHALL объяснять, что новый домен имеет отдельное браузерное хранилище и установку. Переезд предлагает экспорт на старом адресе, импорт в локальном режиме нового адреса и при желании подключение аккаунта. Старая установка не удаляется и не перенаправляется автоматически.

#### Scenario: Установлена старая версия Pages
- **WHEN** пользователь переходит по предложению основного сервиса из старой PWA
- **THEN** видит инструкцию переноса и отдельной установки, старое приложение и его записи остаются доступными

#### Scenario: Первый вход на новом домене
- **WHEN** пользователь открыл новый домен без переноса и без входа
- **THEN** пустой локальный набор не описывается как потеря данных старой установки

# Spec Delta

## MODIFIED Requirements

### Requirement: Онбординг на пустой главной
Система SHALL при отсутствии долгов и счетов показывать приветствие «Пока никто никому не должен», объяснение записи долга и разделения счёта, кнопки «Добавить первый долг» и «Разделить счёт», а в локальном режиме также «Восстановить из резервной копии». Текст SHALL достоверно описывать местное хранение либо подключённую синхронизацию. Карточка установки остаётся под действиями по правилам `app-install`.

#### Scenario: Первый запуск
- **WHEN** без аккаунта нет ни долгов, ни счетов
- **THEN** главная показывает приветствие с тремя кнопками и не требует регистрации

#### Scenario: Разделить счёт с пустой главной
- **WHEN** пользователь нажимает «Разделить счёт» на приветствии
- **THEN** открывается создание счёта, если нет блокировки конфликтов

#### Scenario: Восстановление с пустой главной
- **WHEN** пользователь в локальном режиме нажимает «Восстановить из резервной копии»
- **THEN** открывается выбор файла и далее подтверждение импорта, как в настройках

#### Scenario: Приглашение установить на телефоне
- **WHEN** пустая главная открыта в браузере на телефоне
- **THEN** под действиями приветствия видна карточка «Установите на телефон», она не заменяет действия создания и доступного импорта

#### Scenario: Пустой аккаунт
- **WHEN** пользователь открыл пустой аккаунтный набор
- **THEN** онбординг не предлагает прямой импорт в аккаунт и не утверждает, что данные никогда не отправляются на сервер

## ADDED Requirements

### Requirement: Несогласованные общие итоги
Система SHALL при конфликте финансовых версий показывать на главной предупреждение о несогласованных итогах со ссылкой на расхождения. Отображается местный вариант, альтернативные суммы не складываются. Наличие конфликта блокирует финансовые действия по `sync-conflicts`, но смена валюты отображения и просмотр доступны.

#### Scenario: Конфликт остатка
- **WHEN** устройства имеют разные погашения, требующие выбора
- **THEN** главная помечает местные итоги как несогласованные, пользователь может перейти к сравнению и выбрать валюту просмотра без изменения записей

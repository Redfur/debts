# Spec Delta

## ADDED Requirements

### Requirement: Атомарность местного изменения долга
Система SHALL сохранять создание, изменение или удаление долга вместе с затронутой историей и намерением синхронизации целиком. Изменение исходной суммы обновляет операцию создания в том же действии. Успешная местная запись не зависит от ответа сервера; её сетевая ошибка не откатывает.

#### Scenario: Ошибка изменения суммы
- **WHEN** не удалось сохранить обновлённую операцию создания после изменения исходной суммы
- **THEN** прежняя сумма, история и очередь остаются согласованными, частичного изменения нет

#### Scenario: Удаление без сети
- **WHEN** пользователь аккаунта удаляет долг офлайн
- **THEN** долг исчезает из местного учёта, намерение удаления сохранено и переживает перезапуск

### Requirement: Изменения долга при расхождении
Система SHALL применять глобальную блокировку обычных финансовых действий по `sync-conflicts` ко всем входам создания, изменения, погашения и удаления долга. Уже введённые данные не теряются; прямой адрес формы или открытая модалка не обходят блокировку.

#### Scenario: Сохранение из открытого окна
- **WHEN** пользователь открыл изменение заметки до обнаружения конфликта и нажал «Сохранить» после него
- **THEN** новая финансовая запись не создаётся, ввод сохранён для пользователя и показана причина блокировки

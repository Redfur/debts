# Spec Delta

## MODIFIED Requirements

### Requirement: Импорт резервной копии
Система SHALL по кнопке «Импортировать» принимать JSON-файл резервной копии, проверять его формат и перед применением показывать подтверждение со сводкой (число контактов, число долгов, дата и время экспорта в человекочитаемом формате по местному времени). После подтверждения текущие данные полностью заменяются содержимым файла и приложение перезагружается.

#### Scenario: Успешный импорт
- **WHEN** пользователь выбирает корректный файл и подтверждает импорт
- **THEN** данные заменяются, показывается «Данные успешно импортированы», страница перезагружается

#### Scenario: Неверный файл
- **WHEN** выбранный файл не является JSON или не похож на резервную копию
- **THEN** показывается уведомление об ошибке, текущие данные не изменяются

#### Scenario: Отмена импорта
- **WHEN** пользователь отменяет подтверждение импорта
- **THEN** текущие данные не изменяются

#### Scenario: Дата экспорта в подтверждении
- **WHEN** файл экспортирован 15 октября 2026 года в 13:24 по местному времени
- **THEN** подтверждение показывает «дата экспорта — 15 окт. 2026, 13:24»

# Spec Delta

## MODIFIED Requirements

### Requirement: Ручное обновление курса
Система SHALL показывать в настройках блок «Курс валют»: дату курса от источника в человекочитаемом формате («Обновлён 15 окт. 2026») или «Ещё не загружен», и кнопку «Обновить курс», которая принудительно загружает курс. При ошибке загрузки показывается «Не удалось обновить курс. Используется последний известный.»

#### Scenario: Ручное обновление
- **WHEN** пользователь нажимает «Обновить курс» при доступной сети
- **THEN** курс загружается независимо от давности, дата в блоке обновляется

#### Scenario: Ошибка ручного обновления
- **WHEN** пользователь нажимает «Обновить курс» без сети
- **THEN** показывается предупреждение об ошибке, прежний курс продолжает использоваться

#### Scenario: Формат даты курса
- **WHEN** источник вернул курс на дату 2026-10-15
- **THEN** блок показывает «Обновлён 15 окт. 2026»

# Spec Delta

## MODIFIED Requirements

### Requirement: Экран «Контакты»
Система SHALL на экране `/contacts` показывать все контакты (включая тех, у кого нет непогашенных долгов), отсортированные по имени. Каждая строка показывает аватар, имя и непогашенные остатки: «Мне должны: …» и/или «Я должен: …» с суммами по валютам через « + »; при отсутствии долгов — «—».

#### Scenario: Контакт без активных долгов
- **WHEN** у контакта все долги погашены или удалены
- **THEN** он остаётся в списке «Контакты» со строкой «—»

#### Scenario: Пустой список
- **WHEN** контактов нет
- **THEN** показывается сообщение «Пока нет ни одного контакта.»

#### Scenario: Остатки в нескольких валютах
- **WHEN** контакт должен пользователю 1 000 ₽ и 50 $
- **THEN** строка показывает «Мне должны: 1 000 ₽ + 50 $» без конвертации в валюту отображения

### Requirement: Карточка контакта
Система SHALL по адресу `/contacts/:contactId` показывать шапку (назад, аватар, имя, кнопка «Добавить долг»), две карточки сводки «Мне должны» / «Я должен» с остатками активных долгов по валютам (без конвертации; «—», если пусто) и список всех долгов контакта, включая погашенные, от новых к старым.

#### Scenario: Добавить долг с карточки контакта
- **WHEN** пользователь нажимает «Добавить долг» на карточке контакта
- **THEN** открывается форма создания долга с уже выбранным этим контактом

#### Scenario: Контакт без долгов
- **WHEN** у контакта нет ни одного долга
- **THEN** вместо списка показывается «У этого контакта пока нет долгов.»

#### Scenario: Несуществующий контакт
- **WHEN** пользователь открывает `/contacts/<id>` для несуществующего идентификатора
- **THEN** показывается экран «Контакт не найден» с пояснением, что такого контакта нет на этом устройстве, и кнопкой возврата на главную

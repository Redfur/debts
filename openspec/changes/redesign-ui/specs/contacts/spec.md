# Spec Delta

## MODIFIED Requirements

### Requirement: Поиск контакта при создании долга
Система SHALL открывать выбор контакта из формы долга на весь экран: поле поиска с кнопкой «Очистить» и список контактов, отсортированный по имени. Список фильтруется по подстроке имени без учёта регистра, совпадение выделено. У каждого контакта — плашки его активных остатков. Без совпадений показывается «Среди ваших контактов нет «<запрос>»».

#### Scenario: Фильтрация по подстроке
- **WHEN** существуют контакты «Анна Смирнова» и «Иван», пользователь вводит «ан»
- **THEN** в списке остаются оба контакта с выделенным «ан», у Анны — «+10 000 ₽ · −2 300 ₽»
- **AND** ниже пункт «Создать «ан»»

#### Scenario: Нет совпадений
- **WHEN** пользователь вводит «Петя», а такого контакта нет
- **THEN** показывается «Среди ваших контактов нет «Петя»» и пункт «Создать «Петя»» с пояснением «Новый контакт сразу выберется»

#### Scenario: Контактов ещё нет
- **WHEN** у пользователя нет ни одного контакта и поиск пуст
- **THEN** показывается «Контактов пока нет» и «Введите имя — контакт создастся вместе с долгом»

### Requirement: Аватар контакта
Система SHALL отображать контакт круглым аватаром с первой буквой (графемой) имени в верхнем регистре. Пара цветов «фон / буква» выбирается из палитры в 8 пар детерминированно по имени при создании контакта и не меняется. У каждой пары есть значения для светлой и тёмной темы.

#### Scenario: Цвет аватара стабилен
- **WHEN** контакт создан
- **THEN** его аватар одинаков на всех экранах и после перезапуска, а в тёмной теме берётся тёмный вариант той же пары

#### Scenario: Имя начинается с эмодзи
- **WHEN** имя контакта начинается с эмодзи «🎸»
- **THEN** в аватаре показывается «🎸» целиком

### Requirement: Экран «Контакты»
Система SHALL на экране `/contacts` показывать заголовок с числом контактов, поле «Поиск по имени» и все контакты по имени. В строке — аватар, имя и плашки активных остатков по валютам. Если активных долгов нет, но есть погашенные — «Всё погашено»; долгов нет совсем — «Нет долгов». На десктопе список и выбранная карточка контакта стоят рядом.

#### Scenario: Контакт без активных долгов
- **WHEN** у контакта все долги погашены
- **THEN** он остаётся в списке со статусом «Всё погашено»

#### Scenario: Пустой список
- **WHEN** контактов нет
- **THEN** показывается сообщение «Пока нет ни одного контакта.»

#### Scenario: Остатки в нескольких валютах
- **WHEN** контакт должен пользователю 1 500 ¥, а пользователь ему — 380 €
- **THEN** строка показывает плашки «+1 500 ¥» и «−380 €» без конвертации

#### Scenario: Десктоп
- **WHEN** ширина окна 1024 px и больше и пользователь выбирает контакт в списке
- **THEN** его карточка открывается справа от списка, список остаётся видимым

### Requirement: Карточка контакта
Система SHALL по адресу `/contacts/:contactId` показывать:
- шапку «назад», аватар, имя;
- кнопку «Добавить долг»;
- две карточки сводки «Мне должны» / «Я должен» (остатки активных долгов в валюте итогов) и чистую позицию с контактом;
- секции «Открытые N» и «Погашенные N».

#### Scenario: Добавить долг с карточки контакта
- **WHEN** пользователь нажимает «Добавить долг» на карточке контакта
- **THEN** открывается форма создания долга с уже выбранным этим контактом

#### Scenario: Сводка в разных валютах
- **WHEN** контакт должен 1 500 ¥, пользователь ему — 380 €, валюта итогов — RUB, курс доступен
- **THEN** сводка показывает обе суммы в рублях, под каждой — сумма в исходной валюте («1 500 ¥», «380 €»), и строку чистой позиции

#### Scenario: Сводка в валюте итогов
- **WHEN** все долги контакта в рублях, валюта итогов — RUB
- **THEN** под суммами сводки строки с исходной валютой нет

#### Scenario: Сводка без курса
- **WHEN** курса для пересчёта нет
- **THEN** карточки сводки показывают «—» и разбивку по исходным валютам, строка чистой позиции не показывается

#### Scenario: Контакт без долгов
- **WHEN** у контакта нет ни одного долга
- **THEN** вместо секций показывается «У этого контакта пока нет долгов.»

#### Scenario: Несуществующий контакт
- **WHEN** пользователь открывает `/contacts/<id>` для несуществующего идентификатора
- **THEN** показывается экран «Контакт не найден» с пояснением, что такого контакта нет на этом устройстве, и кнопкой возврата на главную

## ADDED Requirements

### Requirement: Поиск на экране «Контакты»
Система SHALL фильтровать список на экране «Контакты» по подстроке имени без учёта регистра по мере ввода в поле «Поиск по имени». Если совпадений нет, показывается «Никого не нашли по «<запрос>»».

#### Scenario: Поиск
- **WHEN** пользователь вводит «ди»
- **THEN** в списке остаётся «Дима (Кипр)»

#### Scenario: Нет совпадений
- **WHEN** пользователь вводит «Петя»
- **THEN** показывается «Никого не нашли по «Петя»»

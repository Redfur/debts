# Design

## Context

Мотивация — в `proposal.md`. Текущее состояние, которое определяет подход:

- **`src/index.css`.** Переменные shadcn (`--background`, `--primary`, …) для `:root` и `.dark`, связанные с Tailwind через `@theme inline`. Плюс переменные из шаблона Vite: `--text`, `--bg`, `--accent-bg`, `--social-bg`, `--code-bg`, `--sans`, `--heading`, `--mono`. Ни одна из них в коде не используется. При этом `:root` задаёт `font: 16px/145% var(--sans)` с системным шрифтом, а `html` переопределяет шрифт на Geist через `font-sans`.
- **Семантических цветов для направлений и статусов нет.** Весь интерфейс монохромный, акцентный цвет есть только у `destructive`.
- **Аватары.** `ContactAvatar` рисует фон из `contact.colorValue` — это hex из фиксированной палитры в 8 цветов (`shared/config/contact-colors.ts`), сохранённый в IndexedDB. Буква всегда белая. На жёлтом `#eab308` контраст около 1.9:1 — это ниже AA.
- **Дублирование.** Суммы и разбивка по валютам собираются вручную в трёх местах (`formatBreakdown` в `HomeTotalsCards`, `ContactListItem`, `ContactDetailScreen`). Число и символ валюты разделены обычным пробелом, поэтому строка может разорваться между ними.
- **Даты:**
  - история долга — `format(…, "d MMM yyyy", { locale: ru })` прямо в `DebtCard`;
  - курс валют — сырая строка `YYYY-MM-DD`;
  - подтверждение импорта — сырой ISO.
- **Зоны касания.** Кнопки по умолчанию 32 px (`h-8`, иконочные `size-8`), `sm` — 28 px. Иконочные «Изменить» / «Удалить» на карточке долга стоят через `gap-1`.
- **Тестов в проекте нет.** Есть проверки: Biome, knip, `tsc` (в составе `build`) и `openspec validate`.

## Goals / Non-Goals

**Goals:**

- Финальные значения из макетов применяются правкой токенов в одном файле и `docs/design-system.md`, без правок слайсов.
- Слайсы не содержат сырых цветов, ручного форматирования сумм и дат, повторяющейся разметки сумм.
- Требования `design-system` проверяются автоматически там, где это дёшево: контраст токенов и отсутствие старых формулировок.

**Non-Goals:**

- Новая компоновка экранов, десктопная раскладка, bottom sheet, новый шрифт — ждут макетов.
- Тестовый фреймворк (vitest, Playwright) в зависимостях проекта.
- Изменение модели данных и формата резервной копии.

## Decisions

### 1. Токены: два уровня в `src/index.css`

- Остаются роли shadcn: `background`, `foreground`, `card`, `primary`, `muted`, `accent`, `destructive`, `border`, `input`, `ring` и т.д. Компоненты UI-кита работают на них без изменений.
- Добавляются семантические роли продукта, каждая с вариантами `DEFAULT` / `foreground` / `muted` (фон-подложка) для `:root` и `.dark`:
  - `owed-to-me`;
  - `i-owe`;
  - `success` (погашен);
  - `warning`.
- Аватары получают пары `avatar-1…8` + `avatar-1…8-foreground`.
- Все токены регистрируются в `@theme inline` как `--color-*`, поэтому доступны утилитами Tailwind (`text-owed-to-me`, `bg-i-owe-muted`, …).
- Типографика:
  - `--font-sans` (сейчас Geist);
  - роль крупной суммы через утилиту `text-amount` (размер и межстрочный интервал);
  - табличные цифры через `tabular-nums` в компоненте суммы.
- Удаляется блок переменных шаблона Vite и правило `font: … var(--sans)` в `:root`. Базовые размеры возвращаются к умолчаниям Tailwind preflight.

*Альтернатива — отдельный файл `tokens.css` или JSON с генерацией.* Отклонена: для 30–40 переменных генерация лишняя, а shadcn CLI ожидает токены в `src/index.css` (`components.json`).

*Временные значения.* Нейтральная база текущего UI. `owed-to-me` — зелёный, `i-owe` — красный: перекликаются с иконкой приложения. Окончательная палитра — по макетам (Open Questions).

### 2. Аватары: hex в данных остаётся, цвет — из токенов

- В IndexedDB по-прежнему хранится hex из палитры. Старые версии приложения и старые бэкапы продолжают работать, миграция не нужна.
- `shared/config/contact-colors.ts` получает функцию «hex → индекс палитры».
- `ContactAvatar` рисует `bg-avatar-N text-avatar-N-foreground`. Для hex вне палитры (теоретически возможно в импортированном вручную файле) — прежнее поведение: фон из `style`, контрастная буква выбирается по яркости.

*Альтернатива — хранить индекс палитры.* Отклонена: меняет формат данных и бэкапа ради того, что решается при отрисовке.

### 3. Общие компоненты и их слои FSD

| Компонент | Слой / путь | Назначение |
|---|---|---|
| `Money` | `shared/ui/money` | Сумма + символ валюты через ` `, `tabular-nums`, размеры `sm` / `md` / `lg` (lg — крупная сумма итогов) |
| `CurrencyBreakdown` | `shared/ui/money` | Список `Money` через « + »; пустой → «—» или ничего (проп) |
| `EmptyState` | `shared/ui/empty-state` | Иконка (опц.), текст, действие (опц.) — для пустых списков |
| `SectionHeader` | `shared/ui/section-header` | Заголовок секции экрана («Контакты», «Долги») |
| `Badge` | `components/ui/badge` | Примитив shadcn (из реестра; при недоступности — вручную в стиле `button`) |
| `DebtDirectionLabel` | `entities/debt/ui` | Подпись «Мне должны» / «Я должен» + иконка (`ArrowDownLeft` / `ArrowUpRight`) + цвет роли; вариант `inline` и `title` |
| `DebtStatusBadge` | `entities/debt/ui` | `Badge` с ролью `success` и текстом «Погашен» |
| `SettingsRow` | `widgets/settings-screen/ui` | Строка настройки: заголовок, пояснение, контрол — в одну строку на любой ширине; используется только в настройках, поэтому не в `shared` |

- Переводы «Мне должны» / «Я должен» переезжают в `entities/debt/translations.ts` и становятся единственным источником. Дубли ключей направлений в `home-screen`, `contact-detail`, `create-debt`, `edit-debt` удаляются.
- Новое FSD-исключение не нужно: `shared/ui` уже существует (`modals`).

### 4. Форматирование дат — `shared/lib/format-date.ts`

- `formatDate(value)` → «15 окт. 2026»; `formatDateTime(value)` → «15 окт. 2026, 13:24».
- Обе функции на date-fns с локалью `ru`.
- Дата курса `YYYY-MM-DD` разбирается как локальная календарная дата (`parseISO` даёт локальную полночь), а не как UTC. Иначе на западе от Гринвича дата съезжала бы на день назад.

### 5. Зона касания 44×44 без увеличения видимых кнопок

- В базовый класс `buttonVariants` добавляется расширяющий псевдоэлемент: `relative after:absolute after:top-1/2 after:left-1/2 after:size-[max(100%,44px)] after:-translate-1/2`. Видимый размер кнопок не меняется — это решение макетов.
- Те же классы получают пункты навигации (`app-shell-nav-styles.ts`) и строки-ссылки контактов: у строк высота и так больше 44 px, проверяется только ширина.
- Соседние иконочные кнопки ставятся с промежутком не меньше 12 px (`gap-3`), чтобы расширенные зоны не перекрывались. В `docs/design-system.md` это записано как правило компоновки.

*Альтернатива — увеличить `size-8` до `size-11` при `pointer: coarse`.* Отклонена: меняет визуальную плотность до появления макетов.

### 6. Автоматическая проверка контраста — `scripts/check-contrast.mjs`

- Скрипт на Node без зависимостей:
  - читает `src/index.css`;
  - разбирает `oklch(...)` и hex для `:root` и `.dark`;
  - переводит в sRGB и считает контраст WCAG по списку пар из того же скрипта (`foreground` / `background`, `muted-foreground` / `card`, `owed-to-me` / `card`, `avatar-N-foreground` / `avatar-N`, …);
  - падает при нарушении порога 4.5 или 3.
- Подключается как `npm run tokens:contrast` и шаг CI.
- Когда придут макеты, скрипт сразу проверит их значения.

*Альтернатива — проверка в браузере (axe).* Отклонена: требует Playwright или axe в зависимостях.

### 7. Порядок миграции

1. Токены.
2. Примитивы (`Badge`, кнопки, `Money`, даты).
3. `entities/debt`.
4. Экраны по одному: главная → контакты → карточка контакта → форма и модалки → настройки → системные элементы.

Каждый шаг сохраняет рабочее приложение, поэтому изменение можно делать несколькими PR.

## Risks / Trade-offs

- **[Временные цвета закрепятся как «финальные»]** → значения помечены в `docs/design-system.md` как временные. Применение макетов — отдельное изменение.
- **[Красный для «Я должен» воспринимается как ошибка или тревога]** → роль `i-owe` отделена от `destructive`, оттенок меняется одним токеном. Вопрос вынесен дизайнеру.
- **[Псевдоэлемент зоны касания перекрывает соседние элементы]** → правило промежутка `gap-3` для соседних иконочных кнопок, проверка вручную на карточке долга и в шапках экранов.
- **[Удаление `font: 16px/145%` в `:root` слегка меняет межстрочный интервал]** → это осознанный возврат к умолчаниям; проверка по скриншотам всех экранов до и после.
- **[Смена подписей направлений путает привыкших пользователей]** → изменение заметное, но однозначное, фиксируется в CHANGELOG.
- **[Контраст проверяется только для перечисленных пар]** → пары перечислены в скрипте и в `docs/design-system.md`. Новый семантический токен без пары — повод для ревью.

## Migration Plan

- Данные не мигрируют.
- Деплой — обычный релиз. Откат — revert изменения, PWA подхватит предыдущую версию через обновление.
- Перед каждым PR: `npm run check`, `npm run knip`, `npm run build`, `npm run spec:validate`, `npm run tokens:contrast`.

## Open Questions

- Финальные значения токенов: палитра, оттенки ролей `owed-to-me` / `i-owe`, шрифт, радиусы, тени. Придут из макетов и меняют только значения в `src/index.css` и таблицу в `docs/design-system.md`.
- Иконки направлений (сейчас `ArrowDownLeft` / `ArrowUpRight` из Lucide) — заменяемы в одном компоненте по макетам.

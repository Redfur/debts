# Spec Delta

## MODIFIED Requirements

### Requirement: Ярлыки на иконке приложения
Система SHALL предоставлять установленному приложению ярлыки «Новый долг» и «Разделить счёт» для русского языка либо «New debt» и «Split a bill» для английского, которые открывают создание долга и создание счёта. Ярлыки появляются там, где система их поддерживает, например по долгому нажатию на иконку на Android.

#### Scenario: Ярлык «Новый долг»
- **WHEN** пользователь на Android долго нажимает иконку «Долги» и выбирает «Новый долг»
- **THEN** приложение открывается сразу на экране «Новый долг»

#### Scenario: Английские ярлыки
- **WHEN** язык интерфейса английский и браузер использует актуальные сведения приложения
- **THEN** ярлыки называются New debt и Split a bill и ведут на прежние экраны создания


### Requirement: Сведения в диалоге установки
Система SHALL сообщать браузеру сведения для диалога установки: название «Долги» / `Debts` и описание на языке интерфейса, иконку, которую можно показывать без обрезки, и скриншоты основных экранов для телефона. Уже установленные копии остаются тем же приложением и не задваиваются.

#### Scenario: Подробный диалог на Android
- **WHEN** пользователь нажимает «Установить» в Chrome на Android
- **THEN** системный диалог показывает название, описание и скриншоты приложения

#### Scenario: Обновление уже установленного приложения
- **WHEN** приложение было установлено до этого изменения и получает новую версию
- **THEN** на экране «Домой» остаётся одно приложение с прежними данными независимо от языка названия

#### Scenario: Смена языка перед установкой
- **WHEN** пользователь выбирает English до установки приложения
- **THEN** приложение передаёт браузеру английские название Debts, описание и ярлыки, сохраняя прежнюю идентичность и адрес запуска

#### Scenario: Уже установленный ярлык
- **WHEN** пользователь меняет язык уже установленного приложения
- **THEN** внутреннее название меняется сразу, приложением предоставлены актуальные локализованные сведения установки
- **AND** фактическое переименование системной иконки и обновление ярлыков происходят по возможностям и правилам браузера/ОС; приложение не обещает мгновенного переименования и не требует удаления данных

## Браузерные проверки

Фактический браузер: **Chromium 141.0.7390.37, Linux, headless, CDP**. Для каждого запуска создавался отдельный профиль в `/tmp/opencode`; реальные пользовательские данные не использовались. Проверены viewport 390×844 и 1440×900. Это не Android Chrome и не Safari.

Запуск dev-сервера:

```sh
npm run dev -- --host 127.0.0.1 --port 4189
```

Общий шаблон запуска (путь CHROME_PATH заменить на доступный Chromium):

```sh
TMPDIR=/tmp/opencode CHROME_PATH=/path/to/chrome \
  DRAWER_TEST_URL=http://127.0.0.1:4189/scripts/localization-fixture.html \
  node scripts/check-drawers.mjs ./localization-field-scenarios.mjs
```

Все следующие сценарии прошли:

### Подписки — `scripts/localization-scenarios.mjs`

Ручной язык сохраняется при `languagechange`, перезагрузки нет, изменение только формата не порождает `languageChanged`.

### Денежные поля — `scripts/localization-field-scenarios.mjs`

Четыре маски при неизменном raw value; суммы, плашки, разбивка, переводы и проценты обновляются без смены языка. Через CDP вводились обе десятичные клавиши, редактировалась середина, выполнялись Backspace/Delete и выделение. Незавершённая дробь сохраняется при смене формата. Неверные вставки сохраняют прежнее значение и показывают связанный FieldError; корректное редактирование снимает ошибку. Проверена атомарная вставка в середину с превышением точности.

Даты и счётчики проверены на ru/en. Дата релиза дополнительно проверена в America/Los_Angeles и Pacific/Kiritimati: день не сдвигается. Числовой формат не меняет даты и 24-часовое время.

### Приложение — `scripts/localization-app-scenarios.mjs`

- Чистый английский запуск даёт USD; смена языка сохраняет предпочитаемую EUR и текущую THB. Новая форма по-прежнему использует RUB.
- Выбор языка (3 пункта) и формата (5 пунктов), галочки, выбор мышью и клавиатурой (стрелка + пробел), возврат фокуса. Русские/английские настройки просмотрены в мобильной и десктопной раскладках.
- После уточнения вида настроек проверено соответствие выбору валюты: на мобильном — нажимаемая строка со значением без отдельного фона и стрелкой вправо; на десктопе — отдельная кнопка значения и некликабельное название. В закрытом выборе формата показан только числовой пример, короткий пункт «По языку» / `By language` присутствует только в списке. Проверки включают возврат фокуса к видимому инициатору на соответствующей ширине.
- Создание долга, изменение и погашение через UI на обоих языках с ручным форматом; ошибки формы переводятся и после их появления. Имена и заметки остаются исходными.
- Черновик с нормализованной суммой `1234.56` восстанавливается после перезагрузки в другой маске. Смена формата не меняет валюту и исходную строку.
- Для всех четырёх способов деления на ru/en выполнены доменное создание счёта, открытие экрана, редактирование и сохранение формы. Проверены доступные ошибки вставки в денежных и процентных полях, сохранность сумм, участников, позиций, скидки и чаевых. Полное заполнение каждого способа создания счёта исключительно кликами не автоматизировано: исходные счета подготавливаются через публичные действия стора.
- Экспорт настоящего JSON-файла и импорт через file input с подтверждением выполнены на ru/en. Версия 3, прежний состав ключей и имя файла сохранены, настройки не попадают в копию и не заменяются импортом.
- Общий сброс: отмена ничего не меняет; подтверждение возвращает системный русский, формат space-comma и обе валюты RUB, сохраняя долг, черновик THB и скрытую плашку. Удаление только данных сохраняет язык/формат после перезагрузки. «Очистить всё» при неподдерживаемом языке возвращает en/comma-dot/USD и удаляет служебную отметку.
- Проверены title, html.lang, manifest link и сброс отложенного install prompt. Синтетическое событие проверяет состояние приложения, а не реальный системный диалог установки.
- Блокировка getter localStorage не ломает запуск, смену предпочтений в памяти или общий сброс.
- История показывает английское обрамление и русские записи без Unreleased.

### Production-обновление и офлайн — `scripts/localization-upgrade-scenarios.mjs`

Старая сборка подготовлена из HEAD `547c1f14aece7d784cd353b28c5f5510fcf07726` через git archive в отдельном временном каталоге; для сборки использован существующий node_modules. Текущий рабочий каталог не переключался.

```sh
TMPDIR=/tmp/opencode CHROME_PATH=/path/to/chrome \
  DRAWER_TEST_URL=http://127.0.0.1:4189/scripts/localization-fixture.html \
  LOCALIZATION_OLD_DIST=/path/to/previous-build/dist \
  node scripts/check-drawers.mjs ./localization-upgrade-scenarios.mjs
```

Стенд последовательно отдаёт прежний и новый production-комплект на одном временном origin. В старой версии записаны долг 1234.56, исходные имя/заметка и черновик THB со строкой `1234.`. Выполнены реальное обновление service worker и активация новой версии. Сохранены данные и прежняя EUR; новый язык определён как en без искусственно сохранённого ru.

Затем сеть отключена средствами CDP. При первом посещении в новой версии открылись настройки, форма счёта и история. Язык переключался ru → en, формат — в ручной space-dot; оба манифеста прочитаны из офлайн-кеша. Офлайн выполнен поиск `BAHT` в английском каталоге. Черновик восстановился как `1 234.`, а в IndexedDB остались `1234.`, THB, прежняя заметка и сумма долга 1234.56.

Не выполнены из-за отсутствия устройств/браузеров:

- установка из Chrome на Android и Safari на iOS;

- обновление ранее установленного ярлыка и проверка отсутствия второй системной иконки;
- нативная экранная клавиатура, touch-scroll и поведение установленной PWA на этих ОС.

Перед закрытием 5.4 на тестовом HTTPS-адресе:

1. Выбрать English до установки: проверить Debts, описание и маршруты New debt / Split a bill там, где shortcuts поддерживаются.
2. На уже установленной русской версии обновить приложение, проверить сохранность записей и единственную установку. Переключить язык и проверить внутреннее название/тексты.
3. Проверить сведения установки и повторное открытие без сети на обоих языках; записать ОС, версию браузера и фактическое поведение ярлыка.

Мгновенное переименование системной иконки не гарантируется: обновление её имени/shortcuts зависит от браузера и ОС. Не требуется удалять приложение или данные ради смены языка. Проверка JSON и desktop-эмуляция не заменяют эти пункты.

# Proposal

## Why

Четырёх доступных валют недостаточно для долгов в поездках и расчётов в других странах. Полный список государственных валют должен оставаться удобным: использованные валюты доступны сверху, а переключение итогов не требует проходить весь каталог и не меняет постоянное предпочтение пользователя.

## What Changes

- Расширить выбор до всех обычных государственных валют, поддерживаемых текущим API курсов; исключить криптовалюты, металлы и расчётные единицы. Каталог и русские названия доступны офлайн.
- Во всех местах выбора валюты добавить поиск по названию и коду, группы «Ваши валюты» и «Остальные валюты». Верхняя группа: валюта языка → предпочитаемая → USD → валюты всех сохранённых долгов по коду, без повторов. Погашенные долги учитываются, удалённые и черновики — нет.
- Разделить прежнюю настройку на «Предпочитаемую валюту итогов» и «Текущую валюту отображения». Обе доступны в настройках и сохраняются отдельно. Выбор предпочитаемой сразу устанавливает и текущую; смена текущей не меняет предпочитаемую.
- На главной переключать только текущую валюту по кругу: валюта языка → предпочитаемая → USD → валюты открытых долгов по коду, без повторов. Текущую валюту вне круга сохранять до нажатия, затем переходить к первой.
- Перенести прежний выбор валюты в оба новых значения; при отсутствии выбора использовать валюту языка (сейчас RUB). Сброс настроек сбрасывает оба значения.
- Сохранить существующее округление до двух знаков, исходные валюты долгов и счетов, кэш курса, зеркала API и работу без сети.

Вне скоупа: криптовалюты и металлы, изменение точности денег, новые языки и выбор языка, ручное закрепление и ранжирование валют, история использований удалённых записей, история курса, смена API, новые зависимости и синхронизация настроек между устройствами. Валюта новых форм по умолчанию остаётся RUB; предпочтение относится только к итогам.

## Capabilities

### New Capabilities

- `currencies`: каталог государственных валют, поиск, персональная верхняя группа и определение валюты языка.

### Modified Capabilities

- `debts`: валюта долга из полного каталога и обновлённый сценарий выбора.
- `exchange-rates`: отдельные предпочитаемая и текущая валюты итогов; загрузка расширенного набора курсов.
- `dashboard`: динамический круг валют открытых долгов с сохранением предпочитаемой валюты.
- `data-management`: перенос прежних предпочтений, совместимость данных и сброс обеих настроек.

## Impact

- `shared/config/currencies`, `shared/lib/storage/schema`, `shared/lib/exchange-rate`, `shared/lib/currency-preference`, форматирование сумм, ключи и сброс client-side настроек.
- `shared/ui/currency-picker`, `shared/ui/amount-field`; подключение групп в создании/изменении долга и счёта, настройках; вычисление использованных валют в `entities/debt`; переключение в `widgets/home-screen`.
- Проверка валют в `entities/debt/model/creation-drafts/validate.ts`, совместимость экспорта/импорта и старого кэша. Структура записей, версия IndexedDB (3), версия бэкапа (3) и версия черновика (1) не меняются: расширяется множество значений строкового кода и ключей карты курсов. Копии версий 1–3 продолжают читаться; старое приложение не обязано поддерживать новые коды валют.
- Для настроек используется локальная миграция прежнего `debts.displayCurrency`, отдельно от доменных данных и бэкапов. Подробности и идемпотентность — в design.
- Обновление документации архитектуры, домена, дизайн-системы и пользовательского changelog при реализации. Публичный источник курсов и сетевой контракт остаются прежними.

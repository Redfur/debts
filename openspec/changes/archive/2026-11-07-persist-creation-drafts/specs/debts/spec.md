# Spec Delta

## MODIFIED Requirements

### Requirement: Создание долга
Система SHALL предоставлять экран `/new` на весь экран, без нижнего меню:
- шапка «Назад» / «Новый долг»;
- контакт (обязательно);
- переключатель направления (по умолчанию «Мне должны») с подсказкой;
- крупное поле суммы (> 0) с кнопкой выбора валюты;
- заметка (необязательно);
- кнопка «Создать долг», закреплённая над клавиатурой.

При успехе долг создаётся активным с операцией «Создание долга», а пользователь возвращается туда, откуда открыл форму.

#### Scenario: Успешное создание с главной
- **WHEN** пользователь открыл «Новый долг» кнопкой «+» на главной, выбрал контакт, ввёл сумму 5 000 и нажал «Создать долг»
- **THEN** долг сохраняется и пользователь возвращается на главную

#### Scenario: Создание с карточки контакта
- **WHEN** форма открыта с карточки контакта (`/new?contactId=<id>`)
- **THEN** при отсутствии черновика контакт предзаполнен, а после создания или выхода через «Назад» пользователь возвращается на карточку этого контакта

#### Scenario: Подсказка направления
- **WHEN** выбран контакт «Анна Смирнова»
- **THEN** при «Мне должны» под переключателем написано «Анна Смирнова вернёт деньги вам», при «Я должен» — «Анна Смирнова ждёт деньги от вас»

#### Scenario: Выбор валюты
- **WHEN** пользователь нажимает кнопку валюты «₽» рядом с суммой
- **THEN** открывается список RUB, USD, EUR, CNY, и выбранная валюта появляется на кнопке

#### Scenario: Контакт не выбран
- **WHEN** пользователь отправляет форму без контакта
- **THEN** под полем контакта показывается ошибка «Выберите или создайте контакт», долг не создаётся

#### Scenario: Некорректная сумма
- **WHEN** сумма пустая или равна 0
- **THEN** поле суммы выделяется, под ним ошибка «Введите сумму больше нуля», долг не создаётся

#### Scenario: Ошибка сохранения
- **WHEN** запись в хранилище не удалась
- **THEN** над кнопкой «Создать долг» показывается «Не удалось сохранить. Попробуйте ещё раз.»

#### Scenario: Продолжение нового долга
- **WHEN** пользователь повторно открывает создание долга с сохранённым черновиком
- **THEN** форма восстанавливает ввод, а «Создать долг» создаёт запись только после прохождения проверки
- **AND** восстановление следует `creation-drafts`; «Назад» сохраняет ввод, предвыбранный контакт не заменяет контакт черновика, после успешного создания соответствующий черновик удаляется

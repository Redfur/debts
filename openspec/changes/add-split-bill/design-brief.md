## 1. Что меняется и почему

Счёт — общая трата на нескольких человек. Приложение считает, кто кому сколько переводит, **минимальным числом переводов**. В долги пользователя попадают только переводы с его участием. Пользователь может:

- заплатить за всех — ему должны;
- быть должником того, кто платил, — он должен;
- вообще не входить в счёт — «посчитал для друзей и скинул скриншот в чат». Тогда его долги не меняются, но счёт сохраняется, и к нему можно вернуться.

Счёт бывает «Активный» и «Закрыт». Если в нём есть мои переводы, он закрывается сам, когда все мои долги по нему погашены. Если моих переводов нет — закрывается вручную.

### Что в концепте устарело

| В концепте | Теперь | Почему |
|---|---|---|
| Тогл «Я тоже участвую · Моя доля не становится долгом» | «Я» — обычный участник: может платить, может делить счёт, может ни то ни другое | Тогл смешивал «ем ли я» и «платил ли я»; сценарий «меня нет в счёте» им не выражался |
| «Кто заплатил: Я за всех / Кто-то другой» | Выбор одного плательщика из участников + режим «Несколько» с суммами | Платить могут несколько человек |
| Кнопка «Создать 2 долга» | «Сохранить счёт» + сводка «Появятся N долгов» / «Ваши долги не изменятся» | Счёт сохраняется, даже если долгов нет |
| Итог шага 2 — только «кому сколько должны мне» | Блок «Кто кому переводит» — все переводы, мои выделены | Нужна полная картина для чата |
| После создания — история контакта | Открывается экран счёта | Счёт — самостоятельный объект |

## 2. Ограничения

- Только токены и компоненты из `docs/design-system.md` (Onest, роли `owed-to-me` / `i-owe` / `accent` / `warning` / `success`, плашки сумм, сегментированный переключатель, шторки, кнопки-пилюли). Новый компонент — только если без него никак, с описанием состояний.
- Направление денег везде кодируется знаком, цветом и подписью, как в дизайн-системе. Переводы между другими людьми — нейтральные, без ролей направления.
- Mobile 390 px — основной. Зоны касания ≥ 44 px, контраст по правилам дизайн-системы, длинные строки (+30 %) не ломают раскладку.
- Офлайн: никаких сетевых состояний у счёта нет.
- Тексты — из specs этого change; улучшения предлагать списком, чтобы их можно было перенести в specs.

## 3. Ключевые сценарии

1. **Я заплатил за всех** — ввёл сумму, добавил людей, «Поровну», сохранил; у меня появились долги «Мне должны».
2. **Заплатил другой** — выбрал плательщиком Анну; у меня один долг «Я должен» Анне.
3. **Платили несколько** — Анна и Иван оплатили частями; приложение показывает, кто кому переводит.
4. **Посчитал для друзей** — меня нет ни в плательщиках, ни в делении; сохранил, сделал скриншот экрана счёта, отправил в чат; позже закрыл счёт вручную.
5. **Вернуться к счёту** — с главной (секция «Счета») или из карточки контакта (метка «Из счёта» на долге).
6. **Исправить счёт** — до первого погашения меняется всё, после — только описание.
7. **Удалить счёт** — с экрана счёта или через «Удалить» на долге из счёта.

## 4. Новые экраны и состояния

### 4.1 Меню «+» — mobile + desktop

- Два пункта: «Новый долг · Один человек, одна сумма» и «Разделить счёт · Ужин, такси — на нескольких» (как в `Fab`).
- Mobile: меню над кнопкой «+» рядом с нижним меню; затемнение или без — предложить.
- Desktop: у «+» в правом нижнем углу. Альтернатива — пункты в боковом меню; выбрать одно.
- Состояния: закрыто, открыто (иконка «+» повёрнута), фокус с клавиатуры.

### 4.2 «Разделить счёт», шаг 1 из 2 — mobile + desktop

- Шапка «Отмена» / «Разделить счёт» / «1 из 2».
- Крупная сумма с кнопкой валюты (как в «Новом долге»), поле «За что — например, ужин».
- **Участники · N:** чипы с аватарами. «Я» всегда первый и не убирается; кнопка «Добавить» открывает полноэкранный выбор с **мультивыбором** и созданием нового контакта («Создать «Петя»»). Нужен макет этого выбора: отмеченные, поиск, счётчик, кнопка «Готово (N)».
- **Кто заплатил:** по умолчанию «Я». Выбор другого участника — как сделать компактно при 6+ участниках (список, чипы, шторка)? Режим **«Несколько»** — у каждого участника поле суммы и строка «Оплачено X из Y» / «Осталось X».
- Кнопка «Далее — как делим», закреплённая над клавиатурой.
- Состояния: пусто; заполнено; «Нужно хотя бы два участника»; «Введите сумму больше нуля»; «Несколько» с неполной оплатой; 10+ участников (перенос чипов, прокрутка); длинное имя.

### 4.3 «Разделить счёт», шаг 2 из 2 — mobile + desktop

- Шапка «назад» / «<За что> · <сумма>» / «2 из 2».
- Переключатель «Поровну / Долями / Суммами».
- Список участников деления:
  - «Поровну» — сумма у каждого и способ исключить участника из деления (в том числе «Я»);
  - «Долями» — степпер или поле доли, рядом сумма;
  - «Суммами» — поле суммы.
  - Подпись под именем по результату: «переведёт вам», «вы переведёте», «рассчитается с Анной», «моя доля, не долг».
- «Распределено X из Y» с полосой; «Осталось распределить X» + «Раскидать поровну»; «Распределено больше суммы на X».
- **Превью «Кто кому переводит»** — компактный список переводов, мои выделены.
- **Сводка последствий:** «Появятся 3 долга: Анна, Иван и Петя должны вам по 1 500 ₽» / «Появится долг: вы должны Анне 1 600 ₽» / «Ваши долги не изменятся».
- Кнопка «Сохранить счёт»; неактивна с подсказкой «Распределите всю сумму, чтобы продолжить».
- Состояния: каждый режим заполнен; «Суммами» с остатком (как `Split3`); перераспределение; «Я» исключён из деления; ошибка сохранения «Не удалось сохранить. Попробуйте ещё раз.».

### 4.4 Экран счёта — mobile + desktop, светлая и тёмная

Главный новый экран. Он же «скриншот для чата»: верхняя часть без прокрутки должна читаться как самостоятельный итог.

- Шапка: «назад», заголовок (описание или «Счёт»), действие «Изменить».
- Сводка: сумма, дата, «Платил я» / «Платила Анна» / «Платили Анна и Иван», способ деления, статус («Активный» / бейдж «Закрыт»).
- **Кто кому переводит:** строки «Петя → Анна Смирнова — 1 000 ₽». Мои переводы — с ролью направления и отметкой «погашен» по связанному долгу; чужие — нейтрально. Пустое состояние «Никто никому не должен».
- При моих переводах — «Вернули X из Y» / «Вернул X из Y» с полосой.
- **Участники:** имя, «заплатил X», «доля Y».
- Действия: «Изменить», «Закрыть счёт» / «Открыть счёт» (только без моих переводов), «Удалить».
- Состояния: я заплатил, часть вернули; я должен; меня нет в счёте; закрыт автоматически; закрыт вручную; 10+ участников и 8+ переводов; загрузка (скелетон); «Счёт не найден» с кнопкой «На главную».

### 4.5 Изменение счёта

- Та же форма в режиме правки (шапка «Изменить счёт»).
- После погашений: только описание; остальное неактивно с пояснением «По долгам этого счёта уже есть погашения, поэтому сумму, участников и деление не изменить. Чтобы исправить их, удалите счёт и запишите заново.» (по аналогии с `EditSheet`).

### 4.6 Подтверждения (шторки)

- «Удалить счёт?» — ««Ужин» на 6 000 ₽ и 3 связанных долга с историей погашений удалятся. Отменить это нельзя.»; вариант без долгов — ««Дача» на 18 000 ₽ удалится. Отменить это нельзя.».
- Тот же текст, открытый с карточки долга из счёта (кнопка «Удалить» на долге).

## 8. Открытые вопросы к дизайну

1. Форма в два шага или один длинный экран? Двухшаговость в spec — допущение концепта.
2. Как показать «Я» среди участников, чтобы было понятно, что «Я» можно исключить из оплаты и деления?
3. «Несколько плательщиков»: переключатель режима или «+ ещё плательщик»?
4. Где выбирать плательщика при 6+ участниках?
5. Меню «+» на десктопе: у кнопки в углу или в боковом меню?
6. Блок «Счета» в карточке контакта (для счетов, где у контакта нет долга со мной) — нужен ли? Сейчас вне скоупа; если макет покажет ценность, это отдельное изменение.
7. Онбординг пустой главной: упоминать ли разделение счёта?

### Ответы в макетах

1. Mobile — два шага («1 из 2», «2 из 2»); desktop — один экран в две колонки «1 · Сколько и кто платил» / «2 · Как делим».
2. «Я» — первый чип, без кнопки «Убрать»; на экране «Участники» — строка «Отмечены · N · вы уже в счёте». Исключение из деления — галочкой («Я делю счёт»), подпись «не делю счёт».
3. Переключатель «Один / Несколько».
4. Шторка «Кто заплатил» по кнопке «Сменить», с выбором одного и кнопкой «Платили несколько».
5. У кнопки «+» в правом нижнем углу.
6. Не нужен; счета видны через метку «Из счёта» и секцию на главной.
7. Да: текст «…Или разделите общий счёт на компанию…» и кнопка «Разделить счёт».

Дополнительно в макетах: тост «Остаток X раскидан поровну» с «Отменить»; подпись о неделимой копейке; пояснение о статусе внизу экрана счёта; «из счёта «Ужин»» в истории долга; строка «Этот долг — часть счёта, поэтому удалится весь счёт.» при удалении с карточки долга.

«Кто кому переводит» перерисован после первой реализации (строки «<кто> → <кому>» читались неоднозначно): группы с переключателем «Кто переводит / Кто получает» — артборды `Split2`, `Bill`, `DeskSplit`, `DeskBill`, `BillKit`, сравнение подач — `TransferOptions`. Пользователь в группах — «Вы» / «Мне переведут», в строках — «кому: мне» / «от: Вы» (в макетах — «вам» / «от вас»); имена контактов — без склонения: «кому: Иван», «от: Петя».

Расхождение с макетами: склонение имён контактов («Заплатила», «рассчитается с Анной», «Вы должны Анне», «Платил я», «Вернул») — приложение не знает пола и падежных форм имени. Решено писать без склонения: «Анна Смирнова · вся сумма», «переводы с: Петя», «Вы должны: Анна Смирнова — 1 600 ₽», «Платили: вы», «оплата X · доля Y», «Возвращено X из Y» (spec `bills`, «Имена в текстах счёта»). Макеты в этих строках не перерисовываются — источник текстов spec.

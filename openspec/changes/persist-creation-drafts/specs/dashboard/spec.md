# Spec Delta

## ADDED Requirements

### Requirement: Незавершённые формы на главной
Система SHALL показывать на главной блок «Незавершённые» при наличии черновиков: «Незавершённый долг» и/или «Незавершённый счёт», у каждого — «Продолжить» и «Удалить черновик». Блок находится под заголовком до основного содержимого, включая приветствие пустой главной. Обычный запуск не перенаправляет пользователя в форму; прямой переход в форму восстанавливает её черновик.

#### Scenario: Два черновика
- **WHEN** приложение запущено с иконки и сохранены черновики долга и счёта
- **THEN** открывается главная с обоими черновиками, пользователь сам выбирает, какой продолжить

#### Scenario: Черновик на пустой главной
- **WHEN** сохранённых долгов и счетов нет, но есть черновик
- **THEN** под заголовком виден блок «Незавершённые», ниже — прежнее приветствие с действиями создания и импорта

#### Scenario: Продолжение
- **WHEN** пользователь нажимает «Продолжить» у счёта
- **THEN** открывается форма с его сохранёнными значениями, режимом и шагом, а «Назад» возвращает на главную

#### Scenario: Удаление с главной
- **WHEN** пользователь подтверждает удаление одного из двух черновиков
- **THEN** его строка исчезает, второй остаётся; при удалении последнего скрывается весь блок

#### Scenario: Черновиков нет
- **WHEN** на устройстве нет черновиков
- **THEN** блок «Незавершённые» не показывается

## MODIFIED Requirements

### Requirement: Быстрое добавление долга
Система SHALL по круглой кнопке «+» («Создать») открывать меню из двух пунктов: «Новый долг» с подписью «Один человек, одна сумма» и «Разделить счёт» с подписью «Ужин, такси — на нескольких». Кнопка на мобильном стоит справа от нижнего меню, на десктопе — в правом нижнем углу, меню раскрывается над ней; доступна на главной, в «Контактах» и в «Настройках». В шапке главной отдельной кнопки нет.

Если черновик выбранного вида существует, система SHALL продолжать его вместо открытия пустой формы. Это правило действует и для кнопок создания на пустой главной.

#### Scenario: Переход к созданию
- **WHEN** пользователь нажимает «+» на главной и выбирает «Новый долг»
- **THEN** при отсутствии черновика открывается экран «Новый долг» без предвыбранного контакта, после сохранения пользователь возвращается на главную

#### Scenario: Переход к разделению счёта
- **WHEN** пользователь нажимает «+» и выбирает «Разделить счёт»
- **THEN** при отсутствии черновика открывается создание счёта: на телефоне — шаг «1 из 2», на десктопе — форма одним экраном

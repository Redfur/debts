# contacts Specification

## Purpose

Контакт — человек, с которым у пользователя есть долги. Capability описывает, как контакты появляются, как выглядят в списках и что показывает карточка контакта.

## Requirements

### Requirement: Неявное создание контакта из формы долга
Система SHALL создавать контакт только в сценарии создания долга: пользователь вводит имя в поле выбора контакта и выбирает пункт «Создать «<имя>»». Отдельного экрана создания, переименования, удаления или архивирования контакта нет. Имя сохраняется с обрезанными пробелами по краям; пустое имя не создаёт контакт.

#### Scenario: Создание нового контакта по имени
- **WHEN** пользователь вводит «Вася» в поиск контакта, а контакта с таким именем нет
- **THEN** в списке появляется пункт «Создать «Вася»»
- **AND** после его выбора контакт сохраняется на устройстве и сразу подставляется в форму долга

#### Scenario: Пустое имя
- **WHEN** пользователь вводит в поиск только пробелы
- **THEN** пункт создания контакта не показывается

### Requirement: Отсутствие дублей контактов
Система SHALL сравнивать имена контактов без учёта регистра и не создавать второй контакт с тем же именем: при совпадении используется существующий контакт.

#### Scenario: Имя совпадает с существующим в другом регистре
- **WHEN** контакт «Вася» уже существует и пользователь вводит «вася»
- **THEN** пункт «Создать» не показывается
- **AND** существующий контакт «Вася» доступен для выбора в результатах поиска

### Requirement: Поиск контакта при создании долга
Система SHALL показывать в поле выбора контакта список всех контактов, отсортированный по имени (русская локаль), и фильтровать его по подстроке имени без учёта регистра.

#### Scenario: Фильтрация по подстроке
- **WHEN** существуют контакты «Анна», «Иван», «Иванна» и пользователь вводит «ан»
- **THEN** в списке остаются «Анна» и «Иванна»

#### Scenario: Контактов ещё нет
- **WHEN** у пользователя нет ни одного контакта и поиск пуст
- **THEN** показывается сообщение «Пока нет контактов»

### Requirement: Аватар контакта
Система SHALL отображать контакт круглым аватаром с первой буквой (графемой) имени в верхнем регистре на цветном фоне. Цвет выбирается из фиксированной палитры из 8 цветов детерминированно по имени при создании контакта и далее не меняется.

#### Scenario: Цвет аватара стабилен
- **WHEN** контакт создан
- **THEN** его цвет аватара сохраняется вместе с контактом и одинаков на всех экранах и после перезапуска приложения

#### Scenario: Имя начинается с эмодзи
- **WHEN** имя контакта начинается с эмодзи или составного символа
- **THEN** в аватаре показывается этот символ целиком, без разрыва

### Requirement: Экран «Контакты»
Система SHALL на экране `/contacts` показывать все контакты (включая тех, у кого нет непогашенных долгов), отсортированные по имени. Каждая строка показывает аватар, имя и непогашенные остатки: «Вам должны: …» и/или «Вы должны: …» с суммами по валютам через « + »; при отсутствии долгов — «—».

#### Scenario: Контакт без активных долгов
- **WHEN** у контакта все долги погашены или удалены
- **THEN** он остаётся в списке «Контакты» со строкой «—»

#### Scenario: Пустой список
- **WHEN** контактов нет
- **THEN** показывается сообщение «Пока нет ни одного контакта.»

#### Scenario: Остатки в нескольких валютах
- **WHEN** контакт должен пользователю 1 000 ₽ и 50 $
- **THEN** строка показывает «Вам должны: 1 000 ₽ + 50 $» без конвертации в валюту отображения

### Requirement: Карточка контакта
Система SHALL по адресу `/contacts/:contactId` показывать шапку (назад, аватар, имя, кнопка «Добавить долг»), две карточки сводки «Должен вам» / «Вы должны» с остатками активных долгов по валютам (без конвертации; «—», если пусто) и список всех долгов контакта, включая погашенные, от новых к старым.

#### Scenario: Добавить долг с карточки контакта
- **WHEN** пользователь нажимает «Добавить долг» на карточке контакта
- **THEN** открывается форма создания долга с уже выбранным этим контактом

#### Scenario: Контакт без долгов
- **WHEN** у контакта нет ни одного долга
- **THEN** вместо списка показывается «У этого контакта пока нет долгов.»

#### Scenario: Несуществующий контакт
- **WHEN** пользователь открывает `/contacts/<id>` для несуществующего идентификатора
- **THEN** показывается экран «Контакт не найден» с кнопкой возврата на главную

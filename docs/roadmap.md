# Roadmap

Идеи развития продукта. Это не спецификация: каждый пункт берётся в работу как отдельное изменение OpenSpec (`/opsx:propose "<идея>"`), а после реализации и архивирования попадает в [`openspec/specs/`](../openspec/specs). Реализованное — в [CHANGELOG.md](../CHANGELOG.md).

## Ближайшее

- **Редизайн интерфейса** по новым макетам — см. [design-brief.md](./design-brief.md).

## Контакты

- Экран/редактирование контакта: переименование, ручной выбор цвета аватара.
- Удаление и архивирование контактов (сейчас контакт без долгов остаётся навсегда; поле `archivedAt` зарезервировано).

## Долги

- Операция «корректировка» (изменение суммы после погашений без создания нового долга).
- Сроки погашения (due date) и напоминания.
- Фильтр/поиск по долгам, показ погашенных отдельно.

## Валюты

- Пользовательский набор валют (сейчас фиксированный RUB/USD/EUR/CNY).
- История курса, а не только последнее значение.

## Платформа

- Автотесты (unit для агрегатов и бэкапа, e2e для основных сценариев).
- Локализация интерфейса (сейчас только `ru`).
- Backend + синхронизация между устройствами: `ApiStorageAdapter` с тем же интерфейсом `StorageAdapter`, аккаунт.

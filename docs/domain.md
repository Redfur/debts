# Домен

Термины и модель данных. Нормативное поведение — в [`openspec/specs/`](../openspec/specs).

## Термины

| Термин | Значение |
|--------|----------|
| **Контакт (Contact)** | Человек, с которым связаны долги. Создаётся только из формы долга или выбора участников счёта (по имени, без дублей без учёта регистра). Цвет аватара детерминирован по имени. Не удаляется, даже если долгов не осталось. |
| **Долг (Debt)** | Запись: контакт, направление, валюта, исходная сумма (`principalAmount`), заметка, статус. Направление/сумма/валюта редактируются, только пока нет погашений; заметка — всегда. |
| **Операция (DebtOperation)** | Событие истории долга: `initial` (создание, сумма = `principalAmount`) или `repayment` (погашение). |
| **Остаток** | `max(0, principalAmount − Σ repayment.amount)`. При 0 долг закрывается (`closed`). |
| **Направление** | `owed_to_me` — «Мне должны» (контакт должен пользователю); `i_owe` — «Я должен». Встречные долги не взаимозачитываются. |
| **Валюта отображения** | Настройка (по умолчанию RUB), в которую конвертируются только итоги на главной. |
| **Курс валют (ExchangeRatesCache)** | Курсы поддерживаемых валют к USD, кэш на устройстве, обновление не чаще раза в сутки. |
| **Счёт (Bill)** | Общая трата на нескольких участников: сумма, валюта, кто сколько заплатил, способ деления (`equal` / `shares` / `amounts` / `items`). Участник — контакт или «Я» (`ref: "me"`). Статус не хранится: при моих переводах счёт «Закрыт», когда погашены все его долги, без них — по `manualClosedAt`. |
| **Деление по чеку** | Способ деления счёта `items`: итог — сумма позиций, доля каждого — сумма «цена / на скольких» по позициям, где он отмечен, считается точно и округляется один раз на весь чек (неделимые копейки — по наибольшему остатку, при равенстве — первым в списке). Плательщик один. |
| **Позиция чека (BillItem)** | Строка чека: название, цена за строку, отмеченные участники и люди без имени. Делится поровну между ними. |
| **Люди без имени** | Входят в деление позиции, но не участники: их доли не дают переводов и долгов (при расчёте балансов их собирает плательщик). |
| **Баланс участника** | Заплатил минус доля (в копейках). Сумма балансов счёта = 0. |
| **Перевод** | Вычисляемая пара «кто → кому, сколько», обнуляющая балансы; схема переводов минимальна по числу (`minimizeTransfers`). Не хранится. Перевод с «Я» становится обычным долгом с `billId`; переводы между другими участниками долгов не создают. |
| **ContactSummary** | Остатки активных долгов одного контакта по валютам, раздельно по направлениям. |
| **GlobalTotals** | То же по всем контактам + конвертация в валюту отображения (`null`, если для какой-то валюты нет курса). |

```
Contact (1) ──< (N) Debt (1) ──< (N) DebtOperation ("initial" | "repayment")
                     │
                     │ billId (nullable)
                     ▼
                   Bill ── participants[].ref → Contact | "me"
```

## Принципы

- Идентификаторы — UUID (`crypto.randomUUID()`).
- Время — ISO 8601 (UTC).
- Суммы — `number`, округление до 2 знаков на каждой операции; всегда положительные (направление задаёт знак по смыслу).

## Модели (`src/shared/lib/storage/schema.ts`; доменные алиасы — `src/entities/debt/model/types.ts`)

### Contact

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | UUID |
| `name` | string | Имя (обрезано по краям) |
| `colorValue` | string | hex-цвет аватара из палитры 8 цветов, детерминирован по имени (`pickContactColor`) |
| `createdAt` / `updatedAt` | string | ISO |
| `archivedAt` | string \| null | Зарезервировано: фильтруется в списках, но архивирование не реализовано |

### Debt

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | UUID |
| `contactId` | string | Ссылка на `Contact` |
| `direction` | `"i_owe" \| "owed_to_me"` | Кто кому должен |
| `currency` | `"RUB" \| "USD" \| "EUR" \| "CNY"` | Валюта записи |
| `principalAmount` | number | Исходная сумма |
| `note` | string \| null | Заметка |
| `status` | `"active" \| "closed"` | `closed` — остаток достиг 0 |
| `createdAt` / `updatedAt` | string | ISO |
| `closedAt` | string \| null | Момент полного погашения |
| `billId` | string \| null | Счёт, из которого создан долг; `null` — обычный долг. Направление, сумма и валюта такого долга меняются только через счёт, удаление удаляет весь счёт |

### DebtOperation

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | UUID |
| `debtId` | string | Ссылка на `Debt` |
| `kind` | `"initial" \| "repayment"` | Тип |
| `amount` | number | Сумма (> 0) |
| `note` | string \| null | Заметка (у `initial` всегда `null`; заметка долга хранится в `Debt.note`) |
| `createdAt` | string | ISO |

### Bill

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | UUID |
| `title` | string \| null | «За что»; заметка связанных долгов |
| `currency` | CurrencyCode | Валюта счёта и его долгов |
| `totalAmount` | number | Сумма счёта |
| `splitMode` | `"equal" \| "shares" \| "amounts" \| "items"` | Поровну / Долями / Суммами / По чеку |
| `participants` | `BillParticipant[]` | Порядок важен: задаёт раздачу неделимых копеек и порядок переводов |
| `items` | `BillItem[]` | Позиции чека; `[]` у остальных способов деления (и у счетов, записанных до деления по чеку) |
| `manualClosedAt` | string \| null | Ручное закрытие (только у счёта без моих переводов) |
| `createdAt` / `updatedAt` | string | ISO |

`BillParticipant`:

| Поле | Тип | Описание |
|------|-----|----------|
| `ref` | string | `"me"` или id контакта |
| `paid` | number | Сколько заплатил (сумма по участникам = `totalAmount`) |
| `inSplit` | boolean | Участвует в делении; у `items` — отмечен хотя бы в одной позиции |
| `shareInput` | number \| null | Число долей (`shares`) или сумма доли (`amounts`); для `equal` и `items` — `null` |

`BillItem`:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | UUID |
| `title` | string \| null | Название; без него на экране — «Позиция» |
| `price` | number | Цена за всю строку (> 0) |
| `refs` | string[] | Отмеченные участники (`"me"` или id контакта) в порядке `participants` |
| `extraPeople` | number | Люди без имени, 0…99; «на скольких» = `refs.length + extraPeople` ≥ 1 |

### ExchangeRatesCache (в `meta`)

| Поле | Тип | Описание |
|------|-----|----------|
| `base` | CurrencyCode | `USD` |
| `date` | string | Дата курса от источника (`YYYY-MM-DD`) |
| `fetchedAt` | string | ISO, момент локального сохранения (для троттлинга) |
| `rates` | `Record<CurrencyCode, number>` | Курсы к `base` (`NaN`, если валюты нет в ответе) |

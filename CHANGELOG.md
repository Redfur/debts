# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). В заголовке версии **без** префикса `v` (например `1.2.3`); в git тег задаётся с префиксом: `v1.2.3`.

Заметные изменения поведения и UX (новые сценарии, изменения экранов, хранилища под пользовательские действия) фиксируйте в разделе **[Unreleased]** в том же изменении, что и код — чтобы история релизов оставалась полной.

## [Unreleased]

### Added

- Разделение счёта: кнопка «+» открывает меню «Новый долг / Разделить счёт». В счёте — сумма и валюта, «За что», участники (контакты и «Я»), кто заплатил (один или несколько), деление «Поровну», «Долями» или «Суммами» с «Раскидать поровну». Приложение считает, кто кому переводит, минимальным числом переводов; переводы с вашим участием становятся обычными долгами «Мне должны» / «Я должен», остальные видны только в счёте. Счёт можно сохранить, даже если вас в нём нет.
- Экран счёта: итог, «Кто кому переводит» с переключателем «Кто переводит / Кто получает» и отметкой погашенных, участники с оплатой и долей, прогресс возврата ваших долгов. Счёт закрывается сам, когда погашены все ваши долги по нему, а без ваших переводов — вручную кнопкой «Закрыть счёт».
- Главная: секция «Счета» с активными и свёрнутыми закрытыми счетами; приветствие на пустой главной предлагает «Разделить счёт».
- Карточка долга из счёта: метка «Из счёта» со ссылкой на счёт, «из счёта «…»» в истории; сумма и направление такого долга меняются в счёте, а «Удалить» удаляет весь счёт.

### Changed

- Резервная копия теперь включает счета (формат версии 2): копии прежнего формата по-прежнему загружаются, но **прежние версии приложения не смогут загрузить новую копию**. Подтверждение импорта показывает число счетов.
- Локальная база при первом запуске обновляется до новой версии автоматически, данные сохраняются. Вернуться на версию без счетов на том же устройстве можно только через резервную копию.

- Нижнее меню на телефоне стало прозрачнее: под ним виден размытый контент, в том числе на iPhone с iOS 17 и старше.

### Fixed

- Импорт резервной копии больше не зависает после подтверждения — данные появляются сразу, без перезапуска приложения; на iPhone окно импорта открывается с первого выбора файла.
- «Очистить данные» и «Очистить всё» в настройках больше не зависают.

## [2.0.0] - 2026-10-15

### Added

- Новая дизайн-система по макетам «Долги — макеты»: шрифт Onest с табличными цифрами, палитра светлой и тёмной темы, цвета «Мне должны» / «Я должен», кнопки-пилюли, шторки снизу на мобильном и диалоги по центру на десктопе. Контраст токенов проверяется в CI (`npm run tokens:contrast`).
- Главная: чистая позиция — полоса соотношения и строка «Вы должны на X больше» / «Вам должны на X больше»; фильтр контактов «Все / Мне должны / Я должен» со счётчиками; онбординг на пустой главной с восстановлением из резервной копии; состояние «Нет курса» с кнопкой «Повторить».
- Нажатие на сумму итога на главной переключает «Валюту итогов» на следующую (₽ → $ → € → ¥) и сохраняет выбор в настройках.
- Контакты: поиск по имени, счётчик, статус «Всё погашено»; на десктопе — список и карточка контакта рядом.
- Карточка контакта: сводка «Мне должны» / «Я должен» в валюте итогов с разбивкой по валютам, чистая позиция, секции «Открытые» и «Погашенные».
- Новый долг: выбор контакта на весь экран с подсветкой совпадений и остатками, «Создать «…»» прямо из поиска, подсказка «Анна вернёт деньги вам» / «Анна ждёт деньги от вас», крупное поле суммы и шторка выбора валюты, кнопка «Создать» над клавиатурой.
- Погашение: «Остаток X → останется Y» и кнопка «Погасить полностью».
- Настройки: статус курса «Обновлён 15 октября в 12:40», «Нет сети · курс от 15 октября», «Не удалось обновить» с кнопкой «Повторить».
- Новая иконка приложения (вкладка, установленное PWA, ярлык iOS): знак из макетов — карточка с зелёной и терракотовой полосами; значок вкладки подстраивается под тёмную тему системы.
- Плавающее нижнее меню и круглая кнопка «+» на мобильном, боковое меню с подписью «Данные хранятся только на этом устройстве» на десктопе.

### Changed

- Направление долга везде обозначается знаком «+» / «−», цветом и подписью «Мне должны» / «Я должен».
- Итоги на главной — одна сумма в валюте итогов; разбивка по валютам показывается, только когда нет курса.
- Карточка долга: метка направления и дата, заметка заголовком, «Остаток X из Y» с полосой возврата, кнопки «Погасить» / «Изменить» / «Удалить», история под переключателем «История · N операций». Погашенные долги — компактными строками с бейджем «Погашен».
- Карточка контакта и новый долг открываются на весь экран без нижнего меню.
- Изменение долга после погашений: направление и сумма показаны только для чтения с пояснением, заметку можно менять.
- Новые тексты подтверждений удаления долга, импорта («Загрузить резервную копию?» со сводкой) и сброса; «Экспортировать / Импортировать» → «Сохранить в файл» / «Загрузить из файла».
- Настройки сгруппированы: «Тема» (переключатель), «Валюты», «Язык», «Резервная копия», «Сброс»; на десктопе — карточки с явными кнопками.
- Даты в коротком виде: «12 сен», в другом году — «12 сен 2025».
- Тосты — над нижним меню; экран ошибки получил кнопку «На главную»; скелетоны загрузки повторяют форму экранов.
- Цвета аватаров заменены на палитру из 8 пар для светлой и тёмной темы (у существующих контактов цвет подбирается автоматически).

### Fixed

- В окне погашения остаток долга показывается с разделителями разрядов («2 300 ₽» вместо «2300 ₽»).
- Экран «Контакт не найден» больше не утверждает, что контакт удалён вместе с последним долгом (контакты не удаляются).
- Сброс настроек интерфейса сразу возвращает валюту итогов к рублю без перезагрузки.

## [1.1.0] - 2026-07-02

### Added

- Страница «Контакты» (`/contacts`) со списком всех сохранённых контактов; на главной теперь только контакты с непогашенным долгом.
- Создание долга — отдельная страница `/new` вместо модалки.
- Изменение долга (направление/сумма/валюта — пока нет погашений; заметка — всегда) через новую модалку.
- Удаление долга доступно и для погашенных (закрытых) долгов, не только активных.
- Маска разделения разрядов в поле суммы долга/погашения (`10000` → `10 000`).
- Заметки к операциям (в т.ч. к погашению) отображаются в истории долга — свёрнутой по умолчанию, чтобы не перегружать карточку.

### Changed

- Навигация: три вкладки (Главная / Контакты / Настройки); активная вкладка на карточке контакта зависит от того, откуда на неё перешли.

### Fixed

- Открытие `Select` (или другого вложенного слоя) внутри модального окна больше не закрывает модалку при клике внутри её границ.
- Исправлен потенциальный бесконечный цикл ре-рендера при удалении долга, для которого ещё было открыто диалоговое окно (Zustand-селектор возвращал новый пустой массив на каждый вызов).

## [1.0.1] - 2026-07-02

### Changed

- Заменены favicon и иконки приложения (apple-touch-icon, favicon.ico/svg, web-app-manifest 192/512) на финальные.

## [1.0.0] - 2026-07-02

Первый стабильный релиз.

### Added

- Главная: итоги «мне должны» / «я должен» с конвертацией в валюту отображения и разбивкой по валютам, список контактов с нетто-остатком.
- Создание долга на контакт (поиск существующего или создание нового по имени), направление, сумма, валюта (RUB/USD/EUR/CNY), заметка.
- Погашение долга (частичное или полное) с валидацией остатка; автоматическое закрытие долга при остатке 0.
- Карточка контакта: сводка по направлениям, список долгов с прогрессом погашения и историей операций, удаление долга.
- Курс валют: автообновление не чаще раза в сутки + ручное обновление в настройках, офлайн-фолбэк на последний известный курс.
- Настройки: тема, валюта отображения, статус курса валют, резервная копия данных (экспорт/импорт JSON), сброс данных.
- PWA офлайн-режим (`vite-plugin-pwa`).
